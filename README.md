One line, in the voice of a hardware wallet refusing to sign a transaction at 3 AM:

> Denied. You only wake me at 3 AM when you're lonely and leveraged — I'm your hardware wallet, not your booty call.

## Run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
